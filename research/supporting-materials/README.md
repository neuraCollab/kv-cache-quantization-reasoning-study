# Сопутствующие материалы

Фоновая и подготовительная работа той же дипломной темы, которая **не
является** сутью основного эксперимента (описан в [`../README.md`](../README.md)
и целиком лежит в
[`../kv-cache-reasoning-divergence-study/`](../kv-cache-reasoning-divergence-study/)).
Здесь — то, что собиралось параллельно или до него: литобзор, теоретическая
работа, общий бенчмарк квантизации, ранний прототип пайплайна.

| Папка | Что внутри | Как относится к основному эксперименту |
|---|---|---|
| [`prior-prototype/`](prior-prototype/) | Более ранняя, упрощённая версия пайплайна ("День 1-6" план, KIVI/KVQuant) | Предшественник, полностью заменён `src/kvtrace/` в корне репозитория |
| [`general-kv-cache-quantization-bench/`](general-kv-cache-quantization-bench/) | Бенчмарк VRAM/скорости/perplexity разных схем квантизации на Llama-3-8B | Независимый — не про reasoning-трейсы, не про модели из основного эксперимента |
| [`custom-quantizer-and-theory/`](custom-quantizer-and-theory/) | Литобзор SOTA-методов, формальная теория погрешности квантования KV в long-CoT (32 теста), самописные квантайзеры (RTN → GPTQ → WaterSIC) | Теоретическая база, которая мотивировала тему; практической связи с итоговым пайплайном пока нет |
| [`literature-and-notes/`](literature-and-notes/) | Рабочие заметки и литература | Черновики, не финальный текст |
| [`misc/`](misc/) | Неопределённые остатки (слайды, фото) | Не привязаны к конкретной части работы |

Каждая папка содержит собственный README с более подробным описанием.
