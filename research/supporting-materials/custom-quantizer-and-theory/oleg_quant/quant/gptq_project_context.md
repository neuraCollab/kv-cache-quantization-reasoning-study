# Проект: Разработка алгоритмов квантования и GPTQ с нуля на PyTorch
**Модель:** facebook/opt-125m
**Цель:** Понимание математики сжатия LLM, реализация наивного квантования (Round-To-Nearest) и алгоритма компенсации ошибки GPTQ на чистом PyTorch.

## 1. Введение и базовое квантование (Fake Quantization)
Проект начался с реализации класса `UniformQuantizer` для симуляции 8-битного и 4-битного квантования (Fake Quantization). Веса модели округлялись до сетки целых чисел, но аппаратно оставались в формате `float32`.

**Выявленные проблемы и решения на старте:**
1. **Разделяемое состояние:** Использование одного объекта `UniformQuantizer` для всех слоев приводило к конфликту размерностей, так как параметры масштаба (`scale`) и смещения (`zero-point`) перезаписывались. Решение: независимая копия квантизатора или сохранение параметров внутри самого слоя (как `nn.Parameter`).
2. **Проблема Jupyter Notebook:** Функция `copy.deepcopy` копировала уже измененную in-place модель, из-за чего метрика Perplexity (PPL) была одинаковой для всех тестов. Решение: переинициализация оригинальной модели перед каждым тестом.
3. **Отсутствие ускорения:** Выяснилось, что наивное квантование на чистом PyTorch (CPU) не дает выигрыша в скорости и памяти, так как PyTorch не умеет аппаратно умножать INT8/INT4 матрицы без распаковки во float. Для реального ускорения был предложен переход на формат GGUF и движок `llama.cpp`.

**Результаты качества (PPL):**
* Базовая модель FP32: ~42.18
* Наивное INT8 (per-channel): ~42.12 (качество сохранено)
* Наивное INT4 (per-channel): ~44.10 (заметная деградация)

## 2. Переход к алгоритму GPTQ
Чтобы сжать модель до 4 бит без потери качества, был выбран алгоритм GPTQ. В его основе лежит метод **Optimal Brain Surgeon**: минимизация ошибки не самих весов, а выходного сигнала слоя.

**Математическая база GPTQ:**
* Для вычисления оптимальной компенсации требуется собрать входные активации слоя ($X$).
* На основе активаций строится матрица Гессе (ковариации): $H = X^T X / N$.
* При округлении одного веса возникает ошибка $\delta$. Чтобы сигнал на выходе нейрона не изменился, эта ошибка умножается на строку **обратной матрицы Гессе** ($H^{-1}$) и вычитается из оставшихся (неквантованных) весов в строке.

## 3. Разработка GPTQ: Ошибки и исправления
Был написан пайплайн для сбора активаций через `register_forward_hook` на 128 случайных предложениях из датасета WikiText-2 (с отключенным расчетом градиентов `torch.no_grad()`).

**Критическая ошибка (Разрушение весов):**
Первая версия кода `simple_gptq_layer` использовала прямую матрицу ковариации ($H$) вместо обратной ($H^{-1}$). Из-за противоположных знаков матриц алгоритм не компенсировал ошибку, а усиливал её. Метрика PPL взлетела до 4615.

**Исправленное рабочее решение:**
В код было внедрено вычисление точной обратной матрицы $H^{-1}$ с демпфированием (защитой от деления на ноль). Параметры сетки квантования были заморожены для всей матрицы перед циклом.

```python
import torch
import torch.nn as nn

def simple_gptq_layer(linear: nn.Linear, calib_input: torch.Tensor, quantizer) -> torch.Tensor:
    """Математически корректный GPTQ на чистом Python."""
    W = linear.weight.data.clone()
    W_q = torch.zeros_like(W)

    # Заморозка параметров масштаба для всей матрицы
    _ = quantizer.quantize(W)
    if quantizer.symmetric:
        q_max = 2**(quantizer.bits - 1) - 1
        q_min = -q_max
    else:
        q_min, q_max = 0, 2**quantizer.bits - 1

    # Вычисление обратной матрицы Гессе
    H = calib_input.T @ calib_input
    H = H / calib_input.shape[0]
    
    # Damping (защита от сингулярности)
    damp = 0.01 * torch.mean(torch.diag(H))
    H += damp * torch.eye(H.shape[0], device=H.device)
    H_inv = torch.linalg.inv(H)W

    # Поэлементное квантование с компенсацией
    for row_idx in range(W.shape[0]):
        w = W[row_idx].clone()
        
        s = quantizer.s[row_idx].item() if quantizer.s.numel() > 1 else quantizer.s.item()
        z = quantizer.z[row_idx].item() if quantizer.z.numel() > 1 else quantizer.z.item()
        
        for i in range(len(w)):
            w_i = w[i]
            
            w_q_i = torch.clamp(torch.round(w_i / s) + z, q_min, q_max)
            w_hat_i = (w_q_i - z) * s
            
            error_i = w[i] - w_hat_i
            
            # Компенсация по H_inv
            if i + 1 < len(w):
                compensation = error_i * H_inv[i, i+1:] / H_inv[i, i]
                w[i+1:] -= compensation
                
            w[i] = w_hat_i
            
        W_q[row_idx] = w

    return W_q
